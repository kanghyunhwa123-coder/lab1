## 🌱 소개

이 저장소는 초보자도 쉽게 식물을 고르고 키울 수 있도록 **물 주기, 햇빛, 온도, 난이도, 반려동물 안전 여부**를 한눈에 정리한 가이드입니다.

> 💡 **처음이라면?** 난이도 ⭐ 식물부터 시작해 보세요. 몬스테라, 스투키, 스킨답서스가 대표적입니다.

## 🗺 지역별 식물

> 우리나라 기후대를 기준으로 **노지(실외)에서 겨울을 날 수 있는지**를 정리했습니다.

| 지역 | 겨울 최저기온(평균) | 노지 월동 가능 예시 | 실내에서 들여야 하는 예시 |
|------|:---:|------|------|
| 🏔 중부 내륙 (강원·경기 북부) | -15℃ 이하 | 소나무, 철쭉, 라일락 | 동백, 무화과, 로즈마리 |
| 🏙 중부 (서울·인천·충청) | -10℃ 내외 | 회양목, 수국(일부 품종), 국화 | 동백, 올리브, 관엽식물 |
| 🌾 남부 (전라·경상) | -5℃ 내외 | 동백, 무화과, 치자나무 | 올리브(어린 묘목), 열대식물 |
| 🌊 제주·남해안 | 0℃ 내외 | 동백, 유채, 감귤, 야자류 | 열대 관엽식물 |

## 🃏 식물 상세 카드

> 새 식물을 추가할 때 아래 형식을 복사해서 사용하세요.

### 몬스테라 (*Monstera deliciosa*)

<img src="./images/monstera.jpg" alt="몬스테라" width="300" align="right">

| 항목 | 내용 |
|------|------|
| **분류** | 관엽식물 / 천남성과 |
| **원산지** | 중남미 열대우림 |
| **난이도** | ⭐ 쉬움 |
| **햇빛** | ⛅ 밝은 간접광 (직사광선은 잎이 탐) |
| **물 주기** | 💧💧 겉흙 2~3cm가 마르면 흠뻑 |
| **적정 온도** | 18~27℃ (최저 10℃) |
| **습도** | 60% 이상 선호 |
| **분갈이** | 1~2년에 한 번, 봄 |
| **번식** | 줄기 꺾꽂이 (공기뿌리 포함) |
| **반려동물** | 🐾⚠️ 수산칼슘 성분 — 섭취 시 구강 자극 |

**🌟 관리 팁**
- 잎에 구멍(찢어짐)이 안 생긴다면 빛이 부족한 경우가 많아요.
- 공기뿌리는 자르지 말고 흙 쪽으로 유도해 주세요.

| 월 | 물 주기 | 비료 | 분갈이 | 주요 작업 |

## ❓ 문제 해결 (FAQ)

<details>
<summary><b>잎이 노랗게 변해요</b></summary>

- **아래 잎만 노랗다면** → 자연스러운 노화일 수 있어요.
- **전체적으로 노랗고 흙이 축축하다면** → 과습입니다. 물 주기 간격을 늘리세요.
- **잎끝이 갈색으로 마른다면** → 건조하거나 수돗물의 염소 때문일 수 있어요.

</details>

<details>
<summary><b>줄기가 길고 가늘게 웃자라요</b></summary>

빛이 부족하다는 신호입니다. 창가 쪽으로 옮기거나 식물 생장등을 사용해 보세요.

</details>

<details>
<summary><b>하얀 솜 같은 벌레가 생겼어요</b></summary>

깍지벌레일 가능성이 높아요. 면봉에 알코올을 묻혀 닦아내고, 다른 화분과 격리하세요.

</details>

## 🤝 기여하기

새로운 식물 정보나 관리 팁을 환영합니다!

1. 이 저장소를 Fork 합니다
2. 브랜치를 만듭니다 (`git checkout -b add/plant-name`)
3. [식물 상세 카드](#-식물-상세-카드) 형식에 맞춰 문서를 작성합니다
4. 커밋합니다 (`git commit -m 'Add: 식물 이름'`)
5. Pull Request를 생성합니다

> ⚠️ 반려동물 독성 정보는 반드시 출처를 함께 적어 주세요.
